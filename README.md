## Resumen del curso

Este curso introductorio enseña a estudiantes de secundaria a programar con **Java**, desde qué es programar y el primer "Hola Mundo" hasta variables, decisiones, ciclos, métodos, programación orientada a objetos y un mini proyecto final. El aprendizaje se organiza en diez videos con demostraciones y actividades prácticas en **JDoodle**, sin instalaciones.

- **Duración total:** 60 minutos aproximadamente (10 lecciones).
- **Público objetivo:** Estudiantes de 12 a 17 años sin experiencia previa.
- **Prerrequisitos:** Ninguno.
- **Herramientas necesarias:** Navegador web (Chrome, Firefox, Safari o Edge) y [JDoodle](https://www.jdoodle.com/online-java-compiler).
- **Modalidad:** Videos breves, demostraciones paso a paso y prácticas individuales pausando el video.
- **Repositorio de código fuente:** [java-fundamentals-course-NexusLibre](https://github.com/NexusLibre-1ASI0729-2620-16692/java-fundamentals-course-NexusLibre)

> **Importante:** JDoodle permite escribir y ejecutar Java en el navegador sin instalar programas. Si el programa pide datos con `Scanner`, activa **Interactive** antes de ejecutar (o escribe los datos en **Stdin Inputs**).

- **Descripción:** Guarda varios datos en un array, trabaja con cadenas de texto y crea un salón de estudiantes como un array de objetos para calcular el promedio y buscar por nombre.

### Lección 10: Mini proyecto, buenas prácticas y errores comunes (6 minutos)

- **Descripción:** Integra todo lo aprendido en un registro de estudiantes que pide los datos por teclado y genera un reporte del salón; además, aprende a reconocer y corregir los errores más frecuentes.
- **Enlace:** [Ver la lección](https://youtu.be/XMJnAvIaD5Y)
- **Conclusiones clave:** Clases `Estudiante` y `Registro`, array de objetos, `Scanner` y `nextLine()` para limpiar el Enter, `printf` con `%.2f`; buenas prácticas (nombres claros, sangría, métodos cortos, atributos privados); errores comunes: `ArrayIndexOutOfBoundsException`, `';' expected`, `cannot find symbol`, `==` frente a `equals` e `InputMismatchException`.
- **Proyecto final — Registro de estudiantes:** Agrega a la clase `Registro` un método `contarAprobados()` y muéstralo en el reporte. Extra: un método `buscar(String nombre)` con `equalsIgnoreCase`.
